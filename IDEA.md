Browser-based multiplayer 2D space dogfight game inspired by 1962 Spacewar with Newtonian gravity physics.

* Build deterministic 2D physics engine handling orbital mechanics, ship thrust, central star gravity well.
* Implement real-time peer-to-peer multiplayer sync using WebRTC data channels with WebSocket fallback.
* Render vector visuals via WebGL with CRT phosphor glow post-processing shader.
* Add Gamepad API integration and touch overlay controls for mobile browser support.
